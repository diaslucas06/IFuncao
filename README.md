# IFunção

> Plataforma educacional para o ensino e aprendizagem de matemática focado para o ENEM.

---

## Sobre o Projeto

O **IFunção** é uma plataforma desenvolvida para auxiliar estudantes no processo de ensino-aprendizagem de conteúdos matemáticos, fornecendo ferramentas interativas e suporte pedagógico.

---

## Estrutura do Repositório

Este repositório está organizado em uma arquitetura dividida entre frontend e backend:

* 🎨 **[next-frontend](./next-frontend):** Aplicação web desenvolvida com Next.js, React e Tailwind CSS.
* ⚙️ **[backend](./backend):** API REST em Python desenvolvida com FastAPI/SQLAlchemy, Alembic e banco de dados SQLite.

---

## Como Executar o Projeto

Para rodar a aplicação em ambiente de desenvolvimento local, acesse as instruções detalhadas de cada módulo:

1. Configure e inicie o **[Backend](./backend#readme)**.
2. Configure e inicie o **[Frontend](./next-frontend#readme)**.
